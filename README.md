# FIQ

FIQ is a football intelligence web app focused on match outcome prediction, tactical analysis, and user account flows. The current frontend is built with React and Vite and includes a public landing page, protected prediction and dashboard areas, an admin dashboard, and account management screens.

## What’s Inside

- Public marketing homepage with product highlights and calls to action.
- Auth flow for sign up, login, password reset, and onboarding.
- Protected match prediction experience for signed-in users.
- User dashboard, profile settings, and historical timeline views.
- Admin dashboard for system and dataset management.

## Project Structure

- `frontend/` - React + Vite application.
- `backend/` - Reserved for the server/API layer.

## Frontend Stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Lucide React icons

## Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

## Build for Production

```bash
cd frontend
npm run build
```
